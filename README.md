# FortuneCity Archive (`fortunecity.com/greenfield/bypass/314`)

Historical personal web archive preserving recovered HTML source code from my early web pages (1998–2001), originally hand-coded in Notepad and exported with Trellix Web (HTML Exporter 2.7.3117) and uploaded over dial-up FTP.

## Source & Recovery Notes
- **Original URL:** `http://www.fortunecity.com/greenfield/bypass/314/`
- **Archive Source:** Internet Archive (Wayback Machine) snapshots (captures spanning 2002–2012, with root homepage revision dated `06/11/2001` / `Copyright © 1998/2001`).
- **Completeness:** Root HTML markup was recovered; external subpages, frames (`index_l.htm`, `index_m.htm`, `private.htm`), MIDI/script assets, and image files (such as graphics/dinosaur imagery) were not all captured in the snapshot.

## Topics Covered in Original Pages
- Paragliding / parapente, meteorology, clouds/weather, and flying clubs/federations
- Places and travels across Portugal (including Fornos de Algodres, Algodres, and Linhares da Beira), Macau, Brazil, and Australia
- Astronomy, science, and personal notes
